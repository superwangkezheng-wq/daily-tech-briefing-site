# Gate 6 v2 信息层级审计

## Audit scope

周度洞察详情页的桌面与移动端阅读层级、操作入口、反馈选择和内部预览状态。依据 WBR v2 producer contract、ADR-0001、真实 W31 内部投影及 OpenDesign 单版原型进行 combined UX / accessibility audit。

## User goal and accessibility target

读者应能先理解本期主线，再连续阅读 3–5 篇完整技术专题；每篇专题末尾明确区分产业影响与联想中国区启示，最后只阅读一次期级战略建议，并能导出可编辑 Word 或提交绑定快照的分节反馈。目标覆盖键盘操作、移动端重排、缩放与减少动态偏好。

## Strengths

- 目录只列期级主线、专题、期级建议和证据，没有把审计角色误作页面一级章节。
- 专题正文保持连续长文；角色标签只承担轻量路标，不形成 dashboard 或 PPT 卡片感。
- 每个专题以两列分析块收束，移动端按同一顺序堆叠。
- Word 导出为首要操作，打印/PDF 与校准反馈为次要操作。
- “内部预览 · 未公开”与 artifact/run/version/hash 同屏可见，公开授权不会由内容批准推断。

## UX risks

- 四篇长文加集中证据使页面很长；需依赖粘性目录和稳定锚点降低定位成本。
- 证据引用密度高，如果直接展开完整来源会打断正文，因此正文只显示紧凑编号，完整证据集中到文末。
- 期级建议必须与专题内分析块保持足够视觉间隔，避免被理解为某一专题的附属建议。

## Accessibility risks

- 超长中文标题需要在 360px 宽度自然换行，不能触发横向滚动。
- 移动目录、反馈对话框与复制锚点必须保持可见焦点和语义标签。
- 打印模式需移除粘性导航和交互控件，并避免拆分分析块与建议卡。

## Opportunity areas

- 后续有真实媒体时，按专题与 section kind 就地呈现图片、架构图和 benchmark，并保留坏图替代文本。
- 可在不改变合同的前提下增加目录滚动高亮；当前锚点导航已可用。

## Evidence limits and verification gaps

- W31 真实投影没有媒体，因此本期只能验证空媒体路径和坏图回退，无法视觉验证真实架构图/评测图的裁切。
- 本轮验证覆盖 Codex 内置浏览器的 1440×1000 与 390×844 视口，不等同于完整 WCAG 合规认证。

## Recommendations

保持当前单一主题优先结构。发布前持续以真实投影回归：专题数 0–5、建议 0..N、长标题、坏图、XSS、锚点、DOCX 分节差异、无 token 404 与 v1 快照兼容。
